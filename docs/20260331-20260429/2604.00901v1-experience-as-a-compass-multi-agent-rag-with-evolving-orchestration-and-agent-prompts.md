## 摘要
多智能体检索增强生成（RAG）通过为每个智能体分配特定角色，能够支持需要多步骤、多来源或复杂推理的复杂查询。然而，现有方法依赖于静态的智能体行为和固定的编排策略，导致其在多样化的多跳任务上表现脆弱。我们指出了两个关键局限性：缺乏持续自适应的编排机制，以及个体智能体在行为层面缺乏学习能力。为此，我们提出了HERA，一个分层框架，能够联合演化多智能体编排和角色特定的智能体提示。在全局层面，HERA通过奖励引导的采样和经验积累，优化针对特定查询的智能体拓扑结构。在局部层面，角色感知提示演化通过信用分配和沿操作与行为原则的双轴适应，细化智能体行为，实现有针对性的、角色条件化的改进。在六个知识密集型基准测试中，HERA相比近期基线平均提升了38.69%，同时保持了鲁棒的泛化能力和令牌效率。拓扑分析揭示了涌现的自组织现象，其中稀疏探索产生了紧凑、高效用的多智能体网络，展现了高效的协调和鲁棒的推理能力。

## Abstract
Multi-agent Retrieval-Augmented Generation (RAG), wherein each agent takes on a specific role, supports hard queries that require multiple steps and sources, or complex reasoning. Existing approaches, however, rely on static agent behaviors and fixed orchestration strategies, leading to brittle performance on diverse, multi-hop tasks. We identify two key limitations: the lack of continuously adaptive orchestration mechanisms and the absence of behavior-level learning for individual agents. To this end, we propose HERA, a hierarchical framework that jointly evolves multi-agent orchestration and role-specific agent prompts. At the global level, HERA optimizes query-specific agent topologies through reward-guided sampling and experience accumulation. At the local level, Role-Aware Prompt Evolution refines agent behaviors via credit assignment and dual-axes adaptation along operational and behavioral principles, enabling targeted, role-conditioned improvements. On six knowledge-intensive benchmarks, HERA achieves an average improvement of 38.69\% over recent baselines while maintaining robust generalization and token efficiency. Topological analyses reveal emergent self-organization, where sparse exploration yields compact, high-utility multi-agent networks, demonstrating both efficient coordination and robust reasoning.

### 1. 核心问题与整体含义
*   **研究背景**：基于大语言模型的多智能体系统与检索增强生成（RAG）的结合，为处理复杂、多跳的推理任务提供了新范式。然而，现有方法存在显著局限。
*   **核心问题**：
    1.  **静态编排**：大多采用固定或顺序化的智能体协作流程，无法根据查询的复杂度和需求动态调整协调策略，导致检索不足或开销过大。
    2.  **行为固化**：智能体的行为（由提示定义）是静态的，缺乏从执行经验中学习和改进的能力，容易导致错误传播且难以进行针对性优化。
    3.  **适应成本高**：依赖有监督训练或强化学习进行优化的方法需要大量轨迹数据，成本高昂且难以持续适应动态变化的知识环境。

### 2. 提出的方法论：HERA框架
*   **核心思想**：提出一个**分层演化框架（HERA）**，在不更新大语言模型参数的前提下，通过积累的“经验”同时优化全局的智能体编排策略和局部的角色特定提示。
*   **关键技术细节**：
    *   **三层架构**：
        1.  **全局编排器**：负责为每个查询生成最优的智能体协作拓扑（选择哪些智能体、执行顺序与依赖关系）。其优化受**经验库**指导。
        2.  **经验库**：存储从成功与失败轨迹对比中提炼出的、可泛化的语义化“洞察”。它具有添加、合并、修剪等维护操作，并根据效用和多样性被检索，作为编排的先验知识。
        3.  **执行智能体**：执行具体子任务（如查询分解、检索、答案生成等）。其行为通过**角色感知提示演化**进行优化。
    *   **全局优化（编排器）**：采用**奖励引导的组相对策略优化**。对同一查询采样一组候选拓扑并执行，根据任务性能（如F1）和效率（令牌消耗）进行排序，然后让编排器反思成功与失败的差异，生成语义化的“优势”洞察存入经验库。
    *   **局部优化（智能体）**：**角色感知提示演化（RoPE）**。当编排器识别出导致失败的特定智能体后，RoPE会：
        1.  分析该智能体近期的失败轨迹。
        2.  沿不同行为轴（如彻底性、风险敏感性）生成提示变体，并在原轨迹中重放测试。
        3.  通过对比分析，提取**操作规则**（短期纠错）和**行为原则**（长期策略），合并更新智能体提示。
    *   **拓扑突变**：当持续失败时，系统会探索替换失败智能体或增加新智能体等结构变化，并将新拓扑候选重新投入优化循环。

### 8. 不足与局限
*   **计算成本**：虽然免于梯度更新，但**组采样、轨迹重放、提示变体评估**等过程需要多次调用LLM进行推理，**单次查询的优化开销仍然较高**，可能影响实时性。
